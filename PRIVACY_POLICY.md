# Kebijakan Privasi (Privacy Policy) - Cafella

Kebijakan Privasi ini dibuat untuk menjelaskan bahwa aplikasi **Cafella** dikembangkan sebagai proyek tugas kuliah dan tidak bertujuan untuk menyalahgunakan data pengguna.

### 1. Pengumpulan Informasi
Aplikasi Cafella **tidak mengumpulkan, menyimpan, atau membagikan** informasi pribadi apa pun dari pengguna (seperti nama, alamat email, lokasi, atau data kontak).

### 2. Keamanan
Karena aplikasi ini tidak mengumpulkan data pribadi, maka tidak ada data yang disimpan di server eksternal. Kami berkomitmen untuk memastikan keamanan pengalaman pengguna selama menggunakan aplikasi ini untuk keperluan edukasi.

### 3. Perubahan Kebijakan Privasi
Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu sesuai dengan kebutuhan pengembangan proyek akademik.

### 4. Kontak
Jika Anda memiliki pertanyaan mengenai proyek tugas kuliah ini, Anda dapat menghubungi pengembang melalui repositori GitHub ini.
